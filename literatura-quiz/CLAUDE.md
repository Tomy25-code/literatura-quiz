# Literatura Quiz — Project Instructions

## Project

Bulgarian literature quiz website for матура по български език и литература (Bulgarian language and literature graduation exam).

## Tech Stack

- Vite
- React
- Static JSON data
- No backend
- No API calls

## Data Files

- `src/data/authors.json` — 20 Bulgarian authors
- `src/data/works.json` — 30 literary works
- `src/data/questions.json` — multiple-choice quiz questions

## Rules

- UI language must be Bulgarian at all times.
- Do not modify any JSON data files unless explicitly asked.
- Do not invent literary facts — use only what exists in the JSON files.
- Questions must come from `questions.json`.
- Authors must come from `authors.json`.
- Works must come from `works.json`.
- The site must be mobile-friendly (works well on both mobile and desktop).
- Keep components small and readable.
- Use `localStorage` only for user progress, wrong answers, and preferences.

## Planned Features

1. Home screen
2. Random quiz
3. Quiz by author
4. Quiz by work
5. Quiz by category
6. Wrong answers mode (review previously incorrect answers)
7. Flashcards
8. Results screen
9. Simple statistics
